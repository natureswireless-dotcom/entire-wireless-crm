# Entire Wireless ISP CRM v9.8

- Added Service Signup Date to the customer information screen.
- Added a prominent "Member Since YYYY" indicator.
- Uses the customer's Contract Start / service signup date when available.
- For legacy customers without a recorded Contract Start, the CRM record creation date is used as a fallback so existing records still display a useful member-since year.
- Added Service Signup Date and Member Since as optional fields in the configurable CSV export.
- Preserves Residential -0001 and Business -0002 account suffixes and all v9.7 functionality.
